# 数据源：研报获取（2026-09-29）

## 核心说明（诚实声明）
**卖方研报没有统一的公开 API。** 券商研报全文大多在付费终端（Wind / Choice / 同花顺 iFinD）或券商 App 内，网页端以各家研报摘要、财经媒体转载为主。因此本 skill 的研报获取以**网页搜索为主力路径**，不虚构任何"研报 API"接口。

## 搜索模板（主力）
- `{公司名} 研报 评级 目标价`（如"宁德时代 研报 评级 目标价"）
- `{公司名} {券商名} 研报`（如"贵州茅台 中信证券 研报"）
- `{公司名} 最新研报 券商观点`
- 券商研报栏目页：搜索 `{券商名} 研究所 研报` 找其官网/公众号研报栏目

## 搜索结果处理规则
1. 每条采用的研报信息必须标注**券商名称**和**报告日期**（精确到日；只精确到月份则标注"约 X 月"；若日期来自媒体转载而非研报原文，标注"转载发布日，原文日期未披露"）。
2. 按日期过滤：优先采用 3 个月内的研报；做"分歧点"对比时只用 3 个月内的；超过 3 个月的仅作背景参考并标注日期。
3. 同一公司同一券商有多篇时，取最新一篇，旧篇注明被替代。
4. 摘要来源可信度排序：券商官方渠道（官网/公众号/研究所栏目）> 财经媒体转载（注明媒体名）> 自媒体/股吧搬运（仅作线索，需交叉核实，不单独作为数字来源）。

## 辅助来源
- 公司公告与基本面核对：复用 `cn-announcement-monitor`（东财公告接口）与 `cn-company-fundamentals` 的行情接口，核对公司代码与基础财务数字。
- 研报聚合站：搜索结果中常见的研报摘要站可作为线索入口，但评级/目标价等关键数字需与券商官方或权威财经媒体交叉核对后才可引用。

## 兜底规则
- 搜不到研报正文或摘要：按 SKILL.md Workflow 1b 列出缺失要素，对应项标注"未找到"，不编造评级/目标价。
- 只有自媒体二手转述、无券商名和日期：降级为"市场传闻口径"，明确标注，不作为研报精读的主体。
